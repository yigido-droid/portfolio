# Yiğit Can Kınalı — Personal Portfolio

## Open the website
Open `index.html` in your browser.

## Recommended workflow
Open this folder in VS Code and use the Live Server extension.

## Add your CV
Copy your current English CV into this folder and rename it exactly:
`cv.pdf`

The "View CV" button will then open it.

## Main edits
- Website text: `index.html`
- Design: `style.css`

## Before publishing
Review all text and project descriptions.
No phone number, birth date, driver's-license details or reference contact information are published on the website.
